この本のこと

著者アントワーヌ・ボーヴィリエ(1754–1817)は、革命前にプロヴァンス伯 —— のちのルイ 18 世 —— の officier de bouche を務め、1782 年にリシュリュー通りで 「ラ・グランド・タヴェルヌ・ド・ロンドル」を開きました。パリ最初の本格的なレストランとされる店です。 この本は、宮廷の厨房の技術が革命を経てレストランという新しい場へ移し替えられる、 その転換点に立つ一冊として読めます。

底本は Project Gutenberg #64976(フランス国立図書館 Gallica の画像から起こされたフランス語原文)。 パブリックドメインです。第二巻は Project Gutenberg に収録されていません。 本文は第一巻だけを扱っています —— この本は自分の第二巻を何度も参照するので、 たどれない参照が残ります(網で数えています)。
