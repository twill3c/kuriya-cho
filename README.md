# くりや帖(kuriya-cho)

1814 年にパリで出た料理書 —— A. B. ボーヴィリエ『料理人の技法(L'Art du Cuisinier)』第一巻を、
**いま読める一枚のカードに変える**。

原文は Project Gutenberg #64976(底本は BnF/Gallica の画像)。パブリックドメイン。
第二巻は PG に無いので、本アプリの対象は第一巻だけである。

## 何をしているか

1. 本文を章 32・レシピ 628 に分割する
2. 巻頭の献立 13 個(組 85・皿 488)を段組みから復元する
3. 1814 年の綴りを現代綴りへ寄せる
4. 材料・道具・分量・火加減・工程を色分けする
5. 料理名と本文に日本語を添える

利用者に見えるのは「昔の本が読めるようになった」ということだけで、
仕組みの話は「仕組みを見る」の中に隔離してある。

## この本の分割が持っている三つのオラクル

抽出器の正しさを抽出器で確かめないために、**本書自身が持っている検算**を使う。

| オラクル | 何を検算するか | 実測(2026-09-05) |
|---|---|---|
| 巻末の目次 | 章ごとのレシピ数 | 32 章中 29 章が一致。残り 3 章の差はすべて説明がついた |
| 組見出しの数詞(`Seize Entrées` = 16) | 献立の段組み復元。**本文を一切使わない** | 数詞の読めた 79 組中 77 組が一致 |
| 消費率 | 取りこぼしそのもの | 本文 9,852 行・献立 715 行とも 1.00000(残差 0) |

三つ目は、このリポジトリで実際に取りこぼしを二度見つけた
(斜体見出しの句点が外にある 2 件・献立の第二饗応 26 皿)。
件数オラクルは「いくつ取れたか」しか言わないので、
**取り落としたものの姿は消費率でしか見えない**(HARNESS_CHANGELOG の HC-164)。

## 画面

| 画面 | 何が見えるか |
|---|---|
| 入口 | つまみ一本で、1814 年の版面が今のカードに変わる |
| 探す | 本書に 3 回以上出てくる材料 151 種から引く |
| 読む | 原文 / 現代の綴り / 日本語の三層。材料と手順を色分け、参照はたどれる |
| 卓 | 献立 13 組・皿 488。組見出しの数詞と皿数を突き合わせてある |
| 網 | 本が自分を参照する 307 本。たどれない 73 本も隠さない |

| 仕組み | 数えた結果と、**測って捨てた見込み** |

## 測って壊れた見込み

このアプリは「1814 年の綴りが読解の壁だ」という前提から作りはじめた。**その前提は実測で壊れた。**

| | 語彙集に載らない語 |
|---|---|
| 1814 年・本書の地の文(82,987 語形) | 718 = **0.87%** |
| ↑ 綴りを現代に寄せた後 | 360 = 0.43% |
| 1896 年・同じジャンルの対照(PG #6966) | 998 = **1.62%** |

綴りが現代のものになった後の本のほうが、現代フランス語の語彙集から遠い。
外れる語の多寡を決めているのは綴りの古さではなく、料理語と固有名の密度だった。
教科書に必ず載る `-ans → -ants` も、規則としては書けなかった ——
現代語彙 726 語に当てると 723 語が語でなくなる(`anciens → ancients`)。
落ちた見込みは `SPEC.md` §8 に、すべて残してある。
